## 📖 Description

EcoApp is a gamified mobile application that encourages users to walk and explore their city while discovering nearby food offers.

As the user moves in real life, parts of the map are revealed (fog-of-war system), and restaurants appear dynamically. By collecting food offers, users gain XP and contribute to reducing food waste, CO₂ emissions, and water waste.

### 🔥 Why it's useful

- Promotes walking and exploration
- Raises awareness about food waste
- Gamifies sustainability

### 📊 Compared to other apps

Unlike standard food apps or maps:
- Uses **fog-of-war exploration**
- Includes **game mechanics (XP, levels, achievements)**
- Focuses on **sustainability impact**

### ⚙️ Features

* 🧩 Functional Features
-Fog-of-war map exploration
-Dynamic restaurant spawning (every 50m)
-XP and leveling system
-Achievements system
-Offers tab with distance tracking
-Profile system with login/logout
-Firebase user persistence

* 🛠️ Technical Features
-OpenStreetMap (osmdroid)
-GPS location tracking
-Firebase Authentication
-Firebase Firestore (user stats)
-SharedPreferences (local storage)
-Custom map overlays (Fog system)

* 🌍 Technologies Used
-Kotlin (Android)
-OpenStreetMap (osmdroid)
-Firebase (Auth + Database)
-Android SDK

* 📡 APIs & Sensors
-GPS (real-time location tracking)
-Map tiles (OpenStreetMap)
-Firebase backend

### ▶️ How to Use
1.Open the app
2.Allow location access
3.Walk around to reveal the map
4.Collect food from restaurants
5.Gain XP and level up
